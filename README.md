# Tian — Online Courses Landing Page

Responsive landing page for an online learning platform, built from a Figma Community design.

## 🔗 Links

- **Live Demo:** [https://vitalii1408.github.io/portfolio-landing-01/](https://vitalii1408.github.io/portfolio-landing-01/)
- **Source code:** [github.com/vitalii1408/portfolio-landing-01](https://github.com/vitalii1408/portfolio-landing-01)

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript
- Figma
- GitHub Pages

## ✨ Features

- Responsive layout for mobile, tablet and desktop
- Semantic HTML markup
- Hero, popular courses and other content sections
- Mobile menu

## 🚀 Getting Started

```bash
git clone https://github.com/vitalii1408/portfolio-landing-01.git
cd portfolio-landing-01
```

Open `index.html` in your browser (or use the Live Server extension in VS Code).
